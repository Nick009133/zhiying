# 智赢K线训练助手 · 网页版

A 股 K 线模拟训练工具：随机抽取一段真实历史行情，蒙住未来走势，练习买 / 卖 / 观望，训练盘感。

## 在线使用

<https://nick009133.github.io/zhiying/>

## 说明

- 数据为 500 只随机抽样的 A 股日线（每只最近约 450 个交易日），**仅供学习交流，不构成任何投资建议**
- 训练记录与资金保存在用户自己浏览器的本地存储中，不上传任何服务器
- 桌面版（Windows）覆盖全市场约 5000 只股票，功能更完整

## 技术结构

- 界面与训练逻辑：原桌面版（Electron）源码原样复用
- `shim.js`：把桌面接口替换为浏览器实现（静态 JSON 数据 + localStorage 存档）
- `data/`：精简后的股票清单与 K 线数据
